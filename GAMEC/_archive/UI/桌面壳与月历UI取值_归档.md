## 原 §1 窗口与栅格（桌面壳阶段）


### 1.1 窗口形态（v0.3 修订）

> **术语（v0.3 新增，此前混用）**
> - **面板 Panel** = 用户看得见的那块玻璃，**668 × 768**，圆角 26。**设计基准指的是它。**
> - **窗口 Window** = 面板 + 四周透明的投影外扩，**764 × 864**。这一圈永远不可见，只是给投影腾地方。

| 项 | 值 | 说明 |
|---|---|---|
| **面板** | **668 × 768**（不变） | 一切设计取值的基准 |
| **窗口** | **764 × 864**，无边框、背景透明 | `transparent` + 无边框；`useContentSize: true`；V0.1 **不可缩放**，只可拖动 |
| 标题栏 | **无** | 删除；不再有 40px 标题栏与 46 × 32 控制按钮 |
| 最小化 / 最大化 / 关闭 | **无** | 由**系统托盘**承担：单击显 / 隐；右键菜单 = 显示或隐藏 · 立即同步 · 设置 · 退出 |
| 背景 | **Windows 桌面本身** | 应用不绘制 L1 底色；玻璃透过面板看到的是用户壁纸 |
| 置顶 | 默认**不置顶**（PRD §8 未决 #3） | 随桌面层级 |
| 拖拽区 | 面板顶部 18px 内边距带 + 月份头空白处 | `-webkit-app-region: drag`；所有按钮 / 格子 / 列表行显式 `no-drag` |
| **阴影外扩** | **上 32 / 左右 48 / 下 64**（v0.3 改，原四周 16） | 供 §2 的三层投影渲染，不可被面板占用。原 16px 装不下 `0 18px 44px` 的环境影，投影会被窗口边缘切成直角 |
| **透明区穿透** | **必做** | 面板外那一圈透明区**默认仍然吃鼠标事件**，会挡住桌面图标。须按 [[06_液态玻璃实现文档|06]] §6 用 `setIgnoreMouseEvents(!inside, { forward: true })` 放行，命中判定含圆角。**阻塞级** |

| 项 | 值 | 说明 |
|---|---|---|

| 主面板 | **668 × 768** | 圆角 26；**v0.3 起不再由窗口尺寸减出来，它是基准** |
| 面板内边距 | 上 18 / **左右 14** / 下 14 | v0.1 的 16 会与 7 列排布冲突，本版改 14 |
| 面板内容宽 | **640** | 668 − 28 |
| 日历格 | **88 × 88**，gap 4 | (640 − 6 × 4) ÷ 7 = 88；固定 6 行 |
| 网格总尺寸 | **640 × 548** | 6 × 88 + 5 × 4 |
| 元素间距阶 | 4 · 8 · 12 · 16 · 20 · 24 | 一律 4 的倍数；禁止 6 / 10 / 14 / 18 等中间值出现在**元素之间** |
| 容器内边距 | 14 · 18 · 20 | 面板与浮层的内边距专用值，不进元素间距阶 |
| 圆角阶 | 格子 12 / 封面 10 / 卡片 18~20 / 面板 26 / 浮层 `30 30 26 26` / 胶囊 999 | 浮层贴着面板底，下沿圆角随面板取 26 |
| 最小命中区 | ≥ 30 × 30 | 日历格自身即命中区（88 × 88） |

> **主体区插槽（v0.4 新增）**：上表里 548 高、640 宽的那一段，从 v0.4 起称为**主体区插槽**——它是唯一允许换画法的区域。范式 A（月历）在里面排 7 × 6 的 88 格；范式 C（周列看板）在里面排 7 列 88 宽的封面卡流；范式 B（横向时间轴）在里面排可缩放的横条。**三者共用同一个盒子、同样的列宽 88**，所以切换范式时列不跳、头不动、底栏不动。插槽外的每一行都是范式无关的，见总则 8。

### 1.3 后续拉伸策略（V0.1 不实现，接口先留）

- 列数**恒为 7**，日历格随窗口宽度等比撑开，`grid-template-columns: repeat(7, minmax(0, 1fr))`，格子保持正方形 `aspect-ratio: 1`。
- 面板内外边距、圆角、字号**不随窗口变化**；只有格子和列表行高变化。
- 月份主数字、浮层高度固定，不随窗口缩放。
- 断点：仅一个——小于 640 × 720 时切换为滚动容器。

## 原 §2 玻璃层级（桌面壳阶段）


> **v0.3 路线**：不引入系统 Mica / Acrylic，保留 `transparent` 悬浮窗，玻璃靠**边缘 + 光 + 颗粒 + 投影**成立，**不靠透明度**。取舍与做不到的事见 [[06_液态玻璃实现文档|06]] §2、§7。

| 层 | 角色 | 规格 |
|---|---|---|
| **L1** | **Windows 桌面（不由本产品绘制）** | 应用窗口 `background: transparent`。**v0.3 起不再要求宿主开 Mica / Acrylic**；桌面即底，不做任何处理。极端情况（系统不支持透明窗）才回落实心 `--bg-fallback: #EEF1F6`。无交互 |
| **L2** | 主面板 / Panel | **无 `backdrop-filter`**；填充见下 §2.1；外描边 `1px rgba(15,23,42,.10)`；折射内环见 §2.2；投影见 §2.3；内壁见 §2.4；颗粒层见 §2.5；圆角 26 |
| **L3** | 浮层 / Sheet | `backdrop-filter: blur(44px) saturate(180%)`（**保留，有效**）；填充 `linear-gradient(160deg, rgba(255,255,255,.92), rgba(255,255,255,.86))`；外描边 `1px rgba(15,23,42,.12)`；投影 `0 -2px 4px rgba(15,23,42,.10), 0 -8px 18px rgba(15,23,42,.12), 0 -20px 50px rgba(15,23,42,.20)`；折射内环 / 颗粒层同 L2；圆角 30；遮罩 `rgba(15,23,42,.18)` |

### 2.1 L2 填充（v0.3 改：线性 → 径向，主体 .88）

```css
radial-gradient(135% 105% at 20% -8%,
  rgba(255,255,255,.95)  0%,
  rgba(255,255,255,.90) 26%,
  rgba(255,255,255,.88) 58%,
  rgba(255,255,255,.845) 100%)
```

光心在**左上外侧**，与原 158° 光向一致。**主体 .88 是下限 .86 之上留的余量，不得下调**——依据见 §3.1 的对比度基准说明。

### 2.2 折射内环（v0.3 新增，**强制**）

外描边内侧再叠 1px 渐变环，沿周长由亮转暗，模拟玻璃棱的折射：

```css
linear-gradient(158deg,
  rgba(255,255,255,.98)  0%, rgba(255,255,255,.55) 18%, rgba(255,255,255,.14) 38%,
  rgba( 15, 23, 42,.10) 62%, rgba( 15, 23, 42,.16) 82%, rgba( 15, 23, 42,.22) 100%)
```

用 `mask-composite` 挖成环（配方见 [[06_液态玻璃实现文档|06]] §4.3）。**外描边是外描边、内环是内环，两道分开**——内环左上是白的，不能拿它顶替红线里那道深描边。

### 2.3 投影（v0.3 改：单层 → 三层）

```css
0  1px  2px rgba(15,23,42,.10),   /* 接触影 */
0  6px 14px rgba(15,23,42,.10),   /* 中程影 */
0 18px 44px rgba(15,23,42,.20)    /* 环境影 */
```

需要下方 62px / 侧边 44px / 上方 26px 的空间，§1.2 的外扩即为此设。

### 2.4 内壁（体积感）

```css
inset 0   1px  0        rgba(255,255,255,.92),   /* 顶边镜面，v0.2 已有 */
inset 0  -1px  0        rgba( 15,23,42,.06),     /* 底边，v0.2 已有 */
inset 0  24px 32px -28px rgba(255,255,255,.85),  /* v0.3 新增：顶部体积散射 */
inset 0 -14px 22px -18px rgba( 15,23,42,.16)     /* v0.3 新增：底部厚度 */
```

### 2.5 颗粒层（v0.3 新增，**强制**）

`feTurbulence` 生成的 160 × 160 噪点平铺，`opacity: .05`（区间 .04~.06）、`mix-blend-mode: multiply`、压在内容下方。它同时解决两件事：磨砂质感，以及大面积柔和渐变在 8bit 屏上的色带。**删掉它面板会立刻"变塑料"**，验收时须开关对照一次。

### 2.6 红线与约束

**镜面高光（浅色版关键）**：每层顶边 `inset 0 1px 0 rgba(255,255,255,.92)`，底边 `inset 0 -1px 0 rgba(15,23,42,.06)`。浅色玻璃靠**顶部亮线 + 外侧深描边 + 投影**成立；只给半透明白不加这三样，会在浅色壁纸上彻底消失。

**浅底可读性红线**：壁纸为高亮度纯色（如纯白）时，面板必须仍可辨识——外描边 `rgba(15,23,42,.10)` 与投影 **不得删减或调淡**，这是唯一的边界来源。

**层内元素**不使用 backdrop-filter，改用**相对面板底的提亮量**（v0.3 改，原为绝对 alpha `.45~.72`——面板底抬到 .88 后绝对值会合成到近纯白）：

| 元素 | v0.2（绝对） | **v0.3（相对，叠在 .88 面板上）** | 合成后等效 |
|---|---|---|---|
| 今日格 | 白 .85 | **白 .42** | ≈ .93 |
| 次按钮 / 圆形图标钮 | 白 .62 | **白 .30** | ≈ .916 |
| 月份胶囊 | 白 .55 | **白 .24** | ≈ .909 |
| 列表行（L3 内） | 白 .55 | **白 .24** | — |
| 悬停 `--hover` | 深 .05 | **不变** | — |

原则：层内元素与面板底的明度差保持在 **3~5 个百分点**，靠 1px 描边区分边界，不靠拉大 alpha。

**性能红线（v0.3 改）**：全窗口最多 **1 个** backdrop-filter 元素（**仅 L3**）。L2 不再有 blur，原"不达标则降级为不透明 `#F4F6FA`"的条款**作废**。

## 原 §8.2 日详情浮层（范式 A / C 用）


> **谁用它**（v0.7 修订）：**范式 A / C 用**；**范式 B（时间轴，V0.1 主视图）改用时点悬浮 panel，不挂载本节**（[[07_视图范式_游戏日历|07]] §4.8）；**范式 D（左历右详）也不挂载它**——它的右栏就是把本节内容摊平常驻，取值仍以本节为唯一来源，两处不得各说各话（[[07_视图范式_游戏日历|07]] §6.6）。

L3 sheet，高 420，圆角 `30 30 26 26`，内边距 上 20 / 左右 20 / 下 16。

**顶部区（高 96）**

- 左：日期主数字（`title/sheet` 40px）+ 下方 `caption` 的星期与年月。
- 右：**三项计数**，`metric/num` 数字 + `caption` 标签，横向等距排列，块宽 56：

  | 计数 | 标签 | 数字色 | 对应故事 |
  |---|---|---|---|
  | 成就解锁 | `成就解锁` | `--text-1` | P-7 |
  | 首次启动 | `首次启动` | `--text-1` | P-9 |
  | 发售 | `发售` | `--text-1` | F-1 |

- **计数为 0 的块不显示**；三项皆为 0 时整行不出现。
- 计数与下方事件行是「总量 vs 明细」，不算同一信息重复。

**事件行区（可滚动）**

- 行高 **62**（与封面 46 × 62 等高），圆角 18，`rgba(255,255,255,.55)` 底，行间 gap 8。
- 结构：**类型图标 · 封面 46 × 62 · 游戏名（`body`）· 右侧等宽时间戳（`mono/stamp`）**。类型图标（内联 SVG 描边 14px）：首次启动 = **play**、成就解锁 = **钥匙**、发售 = **日历**（图标待定）；图标色 = 对应事件色（首玩 / 成就 = 主题色，发售 = `--ev-release`）。成就行在图标旁并排 `×N`（同色、`mono` 9px）。
- **禁止出现**：意愿等级标签、「必买 / 打折买 / 观望」等任何解释性文案、发售日说明文案（如「距发售还有 X 天」「本作将于…发售」）。日期与数量以数字直接呈现，不加解释。

**底部**

- 「手动补录」次按钮为 **V0.5 入口**（P-4），**V0.1 不渲染**——按总则 2，V0.1 无对应可用功能的入口一律不出现。

**开合与状态（v0.3 补，原规范未定，实现时一并定死）**

| 项 | 定 | 理由 |
|---|---|---|
| 打开 | 点某日的时点标记 / 日历格 | — |
| **无事件的日期** | **不响应点击**，不弹空浮层 | 总则 2 禁止空状态插画与解释性文案，一个什么都没有的浮层无内容可放。格子加 `cursor: pointer` 作为可点的唯一提示 |
| 收起 | 点遮罩 / `Esc` / 再点同一天 | **浮层内不放关闭按钮**——总则 2，既有手势能完成的入口不加 |
| 切时间 | **自动收起** | 浮层是「某一天」的详情，跨时间留着没有意义 |
| 模态性（v0.5 扩写） | 开着时方向键 / 滚轮 / 触摸滑动**横向纵向一律不响应**——既不切月也不切范式 | 遮罩已经挡住日历，交互也要一致。原文只写了「不切月」，v0.5 引入左右切范式后必须一并挡住 |
| 事件行排序 | **按时间戳升序** | 行右侧就是时间戳，顺着读最自然；三项计数是「总量」，行是「明细」，两者排序无关 |
| 三项计数口径 | 成就按**解锁数量**累加；首玩 / 发售按**款数** | 成就是簇（`×N`），数量才是用户关心的量；首玩 / 发售一款就是一件事 |
| 类型图标（发售） | **日历**（原记「待定」） | 其余沿用：首玩 = play、成就 = 钥匙 |
| 封面缩写 | 英文名多词取**首字母（≤3）**，单词取**前 3 字母**，全大写 | 如 `Elden Ring → ER`、`Baldur's Gate 3 → BG3`、`Hades → HAD` |
| 行区滚动条 | 4px 细条，`rgba(15,23,42,.16)` | 行数可能超出 288px 可视高；完全隐藏会失去可滚动的提示 |
