## 0c. 前端技术方案调研（2026-08-27）移入的条目

| 主题 | 内容 | 状态 | 移出原因 |
|---|---|---|---|
| **前端框架与构建链** | React / Vue / Svelte、打包器、TypeScript | **延后**（V0.2 封装时再评估） | V0.1 基线 = 原生 HTML/CSS/JS、无构建、浏览器直开 |
| **现成时间轴库作渲染层** | vis-timeline / TimelineJS3 / Frappe Gantt / ApexCharts 等 | **不采用** | 信息范式与「中心轴 + 变化坐标」不同构，改造成本高于自研（见 [[01_客户端开发文档\|客户端开发文档]] §2A.2） |
| **CSS scroll-driven animations** | `animation-timeline` / `scroll()` / `view()` | **延后** | 非 Baseline，Firefox 未实现；V0.1 需浏览器直开，待 V0.2 进 Chromium 壳后再评估 |
| **全量 canvas / WebGL 渲染** | 整个时间轴走 canvas | **延后** | 可访问性与文本渲染代价；V0.1 只在密集时点层做 DOM+canvas 混合 |
| **CSS anchor positioning 作主路径** | 浮层锚定定位 | **延后**（仅作渐进增强） | 2026-01 才 newly available（Firefox 147），用户面偏新，主路径用 JS 定位 |
| **底部 L3 日详情浮层** | 点击时点从底部升起的 420 高 sheet | **V0.1 不渲染** | 范式 B 改为时点悬浮 panel（[[07_视图范式_游戏日历\|07]] §4.8）；取值仍在 [[05_UI设计规范_游戏日历\|05]] §8.2，随范式 A / C 回归 |

| **封盘阈值的界面配置** | 设置里暴露沉寂天数 / 时长 / 成就比例三个阈值 | **延后**（V0.5） | V0.1 三个阈值写死（[[02_PRD_游戏日历\|PRD]] §3）；先用真数据看默认值准不准，再决定要不要给用户调 |
| **dormant（浅尝即止）在轴上的表现** | 沉寂够但投入不够的游戏加标记 | **不做** | 轴上给「没玩多久就放下」打标记是价值判断，不是记录（[[07_视图范式_游戏日历\|07]] §4.9） |
| **隐藏偏好跨设备同步** | 「隐藏从未启动」开关存后端 | **延后** | V0.1 存 `localStorage`，后端不存这个偏好 |

> 何时回看：V0.2 封装进 Electron / Tauri（渲染层锁定 Chromium）后，scroll-driven animations 与 anchor positioning 可直接解禁；框架与构建链在时间轴交互定型、代码量上来后再评估。
