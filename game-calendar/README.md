# 游戏日历（Game_C）桌面端 — 仅主日历

游戏日历桌面客户端的**第一阶段实现**：只保留主日历视图，无后端、无数据接口，事件用本地演示数据（mock）渲染。

## 范围（本次）

- ✅ 主日历：月份头（大数字月份 + 前/后月按钮）+ 可滚动月份条 + 星期行 + 7×6 网格 + 底栏两件套（同步状态 + 设置齿轮）
- ✅ 桌面悬浮形态：无边框、透明底、**面板 668×768 / 窗口 764×864**、不可缩放、可拖动（顶部 18px + 月份头为拖拽区）
- ✅ 液态玻璃 L2（浅色，精修假玻璃）：径向填充 .88 + 三层投影 + 1px 折射内环 + 颗粒层 + 内壁 inset；面板外透明区做鼠标穿透
- ✅ 系统托盘：单击显/隐，右键「显示/隐藏 · 立即同步 · 退出」（托盘是唯一退出路径）
- ✅ 事件标记：发售 / 购买 / 首次游玩 / 成就簇，6px 色点、×N、+N 折叠、发售底边满宽色条、今日格高亮
- ✅ **日详情浮层（L3 sheet）**：点有事件的日期从底部升起，高 420；顶部日期 + 三项计数（成就解锁 / 首次启动 / 发售，为 0 的块不显示）；事件行按时间戳升序，类型图标 + 封面占位 + 游戏名 + 时间戳，成就行带 ×N；点遮罩 / Esc / 再点同一天收起，切月自动收起
- ❌ 设置页、登录/首启页、后端、真实数据接口 —— 均未实现

取值与交互依据 `../GAMEC/05_UI设计规范_游戏日历.md`（**v0.3**）与 `02_PRD_游戏日历.md`（v0.6）；玻璃层的原理、配方与验收基线见 `../GAMEC/_archive/UI/06_液态玻璃实现文档.md`（已归档）。

## 技术栈

- Electron（透明无边框悬浮窗 + 托盘），渲染层为**原生 HTML / CSS / JS**，无打包器、无框架。
- 日历网格手写 CSS Grid（`repeat(7, minmax(0,1fr))`），与 UI 规范 §9 一致。
- 玻璃层**不用 `backdrop-filter`**：透明窗下它采样不到 Windows 桌面，是空转。改走「边缘 + 光 + 颗粒 + 投影」的精修假玻璃路线（原理见 06 文档 §1、§3）。

## 窗口与面板（别改错了）

```
窗口 764 × 864   ← BrowserWindow，useContentSize
  ├ 上 32 / 左右 48 / 下 64   透明投影空间，永远不可见
  └ 面板 668 × 768            用户看得见的那块玻璃，圆角 26，一切取值的基准
```

面板尺寸是设计基准，**不要动**；窗口只是给三层投影腾地方（原来四周 16px 装不下 `0 18px 44px`，投影会被窗口边缘切成直角）。
面板外那圈透明区**默认仍然吃鼠标事件**，会挡住桌面图标——`app.js` 的 `bindPassthrough()` + `main.js` 的 `glass:pointer-inside` 负责放行，改窗口尺寸或圆角时记得同步 `RADIUS`。

## 运行

```bash
npm install     # 首次，会下载 Electron 二进制（约 100MB+）
npm run make-icon   # 可选：重新生成托盘图标
npm start       # 启动悬浮日历
```

> 无标题栏 / 无关闭按钮：关闭窗口会**隐藏到托盘**，退出请用托盘右键「退出」。

## 结构

```
main.js             Electron 主进程：透明无边框窗口 + 托盘 + IPC
preload.js          contextBridge（暴露 onSyncNow 等最小接口）
renderer/
  index.html        界面骨架
  styles.css        token + 液态玻璃 L2/L3 + 网格 + 日详情浮层 + 动效
  app.js            渲染与交互（月份切换 / 事件点 / 同步态）
  calendar.js       日历网格纯函数（周一列首、42 格）
  mock-data.js      确定性演示事件（种子随年月）；getDayDetail 的返回结构已对齐后端 get_day_detail
scripts/
  make-icon.js      生成 assets/tray.png（纯 Node PNG 编码）
  smoke.js          逻辑冒烟测试（不启动 Electron）
```

## 待办 / 已知取舍

- **字体**：暂用系统回退（Segoe UI / Microsoft YaHei UI / Consolas / Cascadia Mono），未本地打包 Space Grotesk / JetBrains Mono / Noto Sans SC（UI 规范 §9 要求离线打包，属后续工作）。**字体没打包之前，别凭截图去调玻璃参数**——两个变量还没分开。
- **点击穿透未在真机验证**：`npm start` 后请先试面板外那圈能不能双击到桌面图标（06 §10 ⑥，阻塞级）。
- **不做真·桌面模糊**：已决定不上 Windows 11 `backgroundMaterial: 'acrylic'`——它要求放弃透明窗（圆角只能拿系统的约 8px、自绘投影失效），而且**系统 acrylic 在窗口失焦时会退化成纯色**，本产品常驻桌面、大部分时间失焦，收益远小于代价。取舍详见 06 文档 §2；这条路线做不到的四件事见 §7。
- **改玻璃参数前**：先看 `../GAMEC/开发文档/assets/玻璃验收基线/` 里的三张压力壁纸截图，调完再截一次对照。颗粒层的 `feTurbulence` 有三个坑（滤镜插值空间 / 对比度增益 / 混合模式），照抄 06 §4.4，别自己简化。
- **同步状态**为演示态；「设置」齿轮为占位（设置页未实现）。
- 后续接口位：事件数据应由 `get_month_events` / `get_day_detail` 提供（见 `../GAMEC/开发文档/02_前端功能文档.md` §8），届时替换 `mock-data.js`。
